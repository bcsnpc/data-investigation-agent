## DECIDED WITHOUT REVIEW

The model selects one typed tool or proposes an evidence-cited outcome. Tools accept only registered targets, admitted scopes and discovered layer identities; they cannot accept generated SQL, credentials, arbitrary filters or new permissions. The existing pipeline remains the default. The installation may independently select LIVE versus LOCAL_EXPORTED and PIPELINE versus AGENT.

The agent's short action summary, tool arguments and returned evidence IDs are durable public progress. It is not private reasoning. Tool evidence is persisted before the loop may cite it. Questions use the existing ticket comment thread; absence of a real reply never supplies a scope decision.

An outcome proposal does not confer support roles. The trusted tool ledger builds support from original attested observations and existing producer judgments. Existing outcome, support, question-coverage and narrative validation still run before delivery. The proposed claim text is not evidence and is not copied into the output. Missing producers remain capability gaps; timestamps alone cannot become latency evidence.

The first loop has a maximum of 25 decisions and a configurable wall deadline, with the existing diagnostic and physical allowances. Model calls reserve the entire provider request and maximum output before dispatch, retain uncertain charges on failure, and use the shared dollar guard. Restarting a provider wrapper does not reset its recorded session call count. The real provider refuses to construct without dollar admission configured.

Exact tapes gain version 9 for the new agent operation; versions 1–8 retain their recorded operation contracts. This is not a retroactive upgrade of earlier runs. Projected installations keep their existing atomic capture boundary.
