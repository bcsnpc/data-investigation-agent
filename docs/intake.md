

## Round 23 guided intake

`IntakeRequest/1` requires a graph-catalog report, issue type and comparison
kind. Page and visual are optional; when supplied their containment is checked
and the visual's measure candidates are read from graph edges. Report URLs
contribute untrusted explicit filters without being opened. Exact numbers,
EMPTY and stated digit precision remain distinct; no tolerance default exists.
Other requires original description and its nearest issue classification.
Free-text prefill only asks one combined catalog-choice question for missing
essentials. Extracted figures and named visuals need exact token-reference
provenance. A supplied target is never replaced to obtain a matching value.

The authenticated workspace API exposes `/api/workspace/guided/schema`,
`catalog`, `reports`, `sources`, `reports/{id}/pages`,
`reports/{id}/pages/{id}/visuals`, `validate` and `prefill`. An installation
must supply its existing admitted GraphAPI as `workspace.guided_graph`; no
implicit identity or live scope is invented. CLI: `dia intake catalog --graph
<retained-admitted-graph.json>` and `dia intake validate --graph <graph>
--request <request.json>`. These commands work offline. The catalog includes
all admitted scanned reports, separately from the smaller ticket path.

Screenshot lookup holds image bytes in memory and uses an installed vision
port. AI writes the visible-value lookup query; only native rows establish a
key. Two keys produce distinguishing-field choices, not an arbitrary choice;
no rows and a failed read are different results. A truncated lookup cannot
establish uniqueness. Only image hash and extracted field names go to the
shared screenshot audit. Values/query details stay case-scoped. Production vision and attached-image wiring have executed. Screenshot fixtures are faithful synthetic renderings of actual published fixture values, labelled SYNTHETIC_SCREENSHOT in the run records; they are not user-observed reports. Missing optional inventory fields warn. Column-only visual paths recover their TABLE/MODEL ancestors only from literal native parent addresses, including dynamic lineage expansion. The runtime-shaped actual/stripped catalog preflight opens39 routes and retains one genuine unknown-report question across40 dev forms.
