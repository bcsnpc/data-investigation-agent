## Changes and constraints

Acceptance selection pins an immutable context ID and hash. The selected metadata
view leaves the current catalog pointer, current whole-config discovery approval,
enablement and reader scope unchanged. Pins are recorded in the bootstrap and
reinstated in offline replay. A hash mismatch refuses the view. No fixture changed.

Intake inventories quoted values under the consumer-owned SELECTION, SUBJECT and
MENTION enum. Only SELECTION can supply measurement restrictions; BUSINESS_MEANING
must have empty filters and grouping, even when a ticket also mentions a selection.
The role inventory follows the existing procedure evidence contract.

Application SQL now uses the bounded connection retry helper: at most three
attempts, waits of 10 and 20 seconds, only at stage connect and only for published
transient SQL numbers. Each retry is admitted as a new physical request; it does
not consume another logical diagnostic operation. Attempt times, numeric errors,
stage and backoff remain in the query receipt. No query failure, timeout,
authentication refusal or firewall refusal is retried. The evidence gate is unchanged.
The list and minimum-backoff guidance come from
[Microsoft's transient error table](https://learn.microsoft.com/en-us/azure/azure-sql/database/troubleshoot-common-errors-issues?view=azuresql).

F's retained response was completed and ended "with the same total on each side
and no recorded transformation step in between." IncompleteProse mistook the
complete adverbial phrase "in between." for a dangling preposition. The narrow
correction accepts it while continuing to reject "The difference is between."

New technical output records explicitly identified provider mechanism text apart
from the rendered spine. Historical grading reads that explicitly named field
from the sealed provider response and validates it against the original,
receipt-backed synthesis payload. It never guesses paragraph roles from position,
and never alters a historical output or receipt. Reproduction cases grade a
specific addressed cell's verdict/value and answer line; walk outcome stays recorded.
