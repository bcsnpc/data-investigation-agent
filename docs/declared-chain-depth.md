# Declared quantity depth

2026-09-27. Known-domain work; no new freeze or unfamiliar-domain acceptance.

The Microsoft adapter can follow a supported unchanged integral additive column
from a semantic-model declaration through explicit notebook read/write paths.
Static analysis is bounded and never executes the notebook. It resolves exact
Delta locations inside the approved catalog, not global names. There is no
fixture name, metric branch, expected value or mapping in the implementation.

Supported transformations expose join keys/type, possible row multiplication,
whole-row deduplication, modified columns and the original definition excerpts.
The comparison asks whether the same unchanged quantity is conserved across
those operations. It does not assert identical row grain or intended business
behavior. Changed quantity columns, subset deduplication, filters, grouping,
unsupported code and ambiguous declarations remain NOT_COMPARABLE/unresolved.
The current added translation accepts only whole-entity scope without dimensions
or filters. Shared snapshot and key uniqueness remain unestablished.

`run_ticket.py --max-boundaries` sets a pinned per-run ceiling (default one).
It does not authorize reads, establish reachability or prescribe estate depth.
The governing principle is now in CLAUDE.md. Equality continues downward;
divergence invokes the definition judge and may end the walk. Both structured
outputs retain every unchecked boundary/reason and the actual checked depth.

Silver/Bronze reads require an independently metered lakehouse endpoint lookup,
the exact endpoint in the approved discovered context, matching approved server,
the isolated reader, governed SQL and the reader's surface self-report. Missing
attestation stays visible. Metadata credentials never execute quantity reads.

The retained fixture resolves semantic model -> Gold -> Silver -> Bronze offline.
The final producer initializes literal rows; no source-application input is
invented. This result is metadata resolution, not evidence of successful reads.
