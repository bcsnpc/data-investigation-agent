## How this differs

[Soda](https://docs.soda.io/), [Bigeye](https://www.bigeye.com/platform/data-observability), [Acceldata](https://www.acceldata.io/data-ai-observability) and [Elementary](https://docs.elementary-data.com/) monitor data quality and health; several also offer lineage, impact and root-cause investigation. This project's starting point is a dashboard number a person disputes: reconstruct its supported declared report context, compare faithful quantities across the declared path, and explain the supported mechanism or the evidence gap. Their alerts can be intake tickets; an automated alert integration is not delivered. [Fabric Data Agent](https://learn.microsoft.com/en-us/fabric/data-science/how-to-create-data-agent) and [AI/BI Genie](https://docs.databricks.com/aws/genie/set-up) answer questions about data. Default-off proposer interfaces allow approval-time lineage suggestions and untrusted query candidates; assistant answers are never investigation evidence. The first reader lineage response used an unsupported relation kind, and the single Data Agent setup attempt refused its definition format, so no nine-family assistant comparison ran. See [Round Eight evidence](docs/round-eight-research-and-proposers.md).

## What works today

- Supported models and reports enter the approved ticket catalog through discovery. Intake carries the definition target, reported state/precision and cell address into the procedure; ambiguous or unsupported context refuses.
- The engine derives supported lineage from transformation code and verifies proposed bindings with bounded live profiles. All **15 fixture transformation proposals** have reader witnesses. The application Copy Job binding remains separately declared.
- A deterministic walk descends on agreement and classifies supported transformation, load-latency, ingestion-gap and source-consistency evidence. A configured unreachable source ends at the named reachable depth. Neither an unknown filter nor a missing equivalence is approximated.
- Declared report-context reproduction has executed against fixture-authored EMPTY and numeric16 figures, preserving saved-slicer and precision assumptions. It has not been verified against a real user's report selections.
- The hosted acceptance gate has two immutable fifteen-case columns: archived declared-lineage and separately recorded inferred-lineage evidence. Actual-main check [37416970672](https://github.com/bcsnpc/data-investigation-agent/actions/runs/37416970672) passed **15/15 × 2** with zero estate requests; passing includes deliberate holds/refusals. [Closing record and exact manifest variants](docs/round-seven-delivery-record.md).
- Each probe retains physical-request accounting, diagnostic/guard separation, reader identity, execution-surface evidence and snapshot limitations. The local workspace supports reviewed intake, history, cancellation and dual outputs.
- New run records link earlier identical tickets and native cell addresses by identifier only. Technical outputs carry a previous-runs line; business outputs and planner input are unchanged. [History scope and tests](docs/identifier-only-run-history.md).
